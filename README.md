## Rockchip upgrade_tool
This is a free and open-source reimplementation of Rockchip's upgrade_tool. While the existing rkdeveloptool is great, it doesn't have the functionality that allows for update.img firmware upgrade. This program was created using a reverse-engineered version of upgrade_tool and the open-source rkdevtool.
> [!CAUTION]
> Incorrect use of this tool could cause your device to be bricked. This tool is provided AS-IS with NO WARRANTY and the developer of this tool are not responsible for bricked devices. It is always wise to make a backup of your stock firmware before performing any firmware flashes on your device.
